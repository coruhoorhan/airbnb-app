# Triage Labels

The five canonical triage labels:

| Label | Purpose |
|---|---|
| `needs-triage` | New issue, not yet reviewed |
| `needs-info` | Needs more information from reporter |
| `ready-for-agent` | Ready for automated agent processing |
| `ready-for-human` | Requires human judgment |
| `wontfix` | Accepted as not fixable / not doing |
