# Issue Tracker

Issues are tracked as local markdown files under `.scratch/<feature>/`.

## Workflow

1. Create `.scratch/<feature-name>/` directory
2. Write issue as markdown files in that directory
3. Skills that need to create issues (`to-tickets`, `to-spec`, `triage`) write to this path
4. No external CLI needed; files are committed with the code

## Labels

The five canonical triage labels are listed in `triage-labels.md`.
